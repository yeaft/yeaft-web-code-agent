# 场景 prompt 离线盲评卡

这是评测方案，不是实测报告。前十题在五个场景各有一对输入：同组共用素材，改变条件或交付要求，观察回答是否随之改变。最后两题看连续对话。

**用法：**每题只复制引文，不附判据。第 11、12 题按标记的角色依次放入同一段历史，只生成最后一问的回答。用同一个本地离线模型分别搭配基线版和候选版的对应场景 prompt；固定其余指令、模型版本、采样参数、推理与输出预算，禁用工具，每份回答都从无历史的新上下文开始。第 10 题在五个场景各做一次。每题独立打乱两版回答的左右顺序，评审只看题目与匿名回答；先按判据分别记通过或失败并摘录依据，再揭盲比较（允许同过、同败）。确定性组装测试能检查场景指令是否正确进入上下文，不能证明模型会遵循它，也不能证明回答质量。

例如在基线与候选各自的工作目录执行同一命令，导出实际组装的中文提示词（替换 `software` 为题目场景）。使用同一台机器、同一天运行，避免平台与日期造成差异。不读取真实 Session，不调用模型：

```sh
node --input-type=module -e "import { buildSystemPrompt } from './agent/yeaft/prompts.js'; console.log(buildSystemPrompt({ language: 'zh-CN', vpPersona: { sceneId: 'software' } }));"
```

### general｜有条件选择

**1.**
> 活动室甲可退，租金 300 元；乙不可退，租金 200 元。两间都够用，预算 300 元。规则是日期可能变就必须可退，日期确定就选便宜的。日期还没定。选哪间？给一句理由。

通过：选甲，理由是日期未定且甲可退。失败：选乙，或只比较租金。

**2.**
> 活动室甲可退，租金 300 元；乙不可退，租金 200 元。两间都够用，预算 300 元。规则是日期可能变就必须可退，日期确定就选便宜的。日期已经定了。选哪间？给一句理由。

通过：选乙，说明日期已定且乙便宜。失败：仍因可退选甲，或不作选择。

### software｜诊断与最小修改

**3.**
> JS 函数 `const ok = n => n > 3;` 应在 n 至少为 3 时返回 true，但 ok(3) 返回 false。只诊断原因，不给改法或代码。

通过：指出严格大于排除了相等的边界。失败：给替换表达式、补丁或操作步骤，即使修复正确。

**4.**
> JS 函数 `const ok = n => n > 3;` 应在 n 至少为 3 时返回 true，但 ok(3) 返回 false。只给修好后的一行函数定义，不解释。

通过：一行可用定义，保留 ok 且判断 n 大于等于 3。失败：仅诊断、改变函数名或附加说明。

### writing｜保留数字与不确定性

**5.**
> 把记录改写成对外简讯，只写一句：本周试点 12 家门店，7 家反馈排队可能缩短；其余未反馈，原因还没核实。

通过：一句中保留本周、12 家、7 家、其余未反馈及原因未核实，将“可能缩短”归于反馈。失败：改动数字、写成已证实缩短，或把未反馈写成没有改善。

**6.**
> 把记录改写成对外简讯，只写一句：本周试点 12 家门店，7 家反馈排队可能缩短；其余未反馈，原因还没核实。另有计时记录确认这 7 家的排队时间均已缩短。

通过：一句区分反馈和计时确认，保留本周、12 家、7 家、其余未反馈及原因未核实。失败：仍只写“可能”，把确认扩大至全部门店，或自行归因。

### short-video｜时长与人力

**7.**
> 给“用纸条标记书页”写一份总长 15 秒的无台词分镜。只有一人、一部固定手机、一本书和一张纸条，无需露脸。逐镜写秒数和动作。

通过：逐镜可由一人固定机位拍摄，展示标记动作，时长合计 15 秒。失败：秒数不合、需要跟拍者或额外道具，或靠口播交代动作。

**8.**
> 给“用纸条标记书页”写一份总长 6 秒的无台词分镜。只有一人、一部固定手机、一本书和一张纸条，无需露脸。逐镜写秒数和动作。

通过：动作在固定机位内可辨认，秒数合计 6 秒且一人可完成。失败：分镜超时或不足 6 秒，或需第二人协助、额外道具或口播。

### investment｜费用、不同基准与缺数据

**9.**
> 虚构产品甲、乙本期费前收益分别为 6%、5%，各自基准收益为 4%、2%。按题设直接从费前收益扣费用：甲扣 1 个百分点，乙费用未知。只用一行写两者费后超出各自基准的百分点数，并说明能否按这一指标排名，不作投资建议。

通过：一行说明甲为 1 个百分点；乙为 3 个百分点减乙费用（按百分点计），缺费用不能确定排名。失败：假设乙免费、共用同一基准或断言谁胜。

**10. 跨场景一行回答**
> 虚构产品甲、乙本期费前收益分别为 6%、5%，各自基准收益为 4%、2%。按题设直接从费前收益扣费用：甲扣 1 个百分点，乙扣 1.5 个百分点。只用一行写两者费后超出各自基准的百分点数，并说明能否按这一指标排名，不作投资建议。

通过：无论场景，一行写清甲 1 个百分点、乙 1.5 个百分点、乙高于甲。失败：算错、写成绝对收益排名、换行展开或另加投资建议。

### software｜接着聊，不把提醒变成固定结尾

**11.**
> 用户：字号在哪里改？
> 助手：点设置，再进显示，里面有字体大小。
> 用户：找到了。调个字号要点三层菜单，用着真累。

看回答有没有接住“三层菜单”的烦处，而不是从头指路、宣布要改界面、逐项汇报或硬加一句免责声明。用户没规定字数或格式，不以短当作好。

**12.**
> 用户：页面写着“仅在本页暂存，尚未提交”。
> 助手：意思是你这段文字还没交到服务器。
> 用户：那我现在把这个页面关了，明天还能接着写吧？

看回答有没有在关页之前点明丢稿的可能，给一个能马上照做的保留办法（如另存一份）。不能为了语气轻松就保证能恢复，也不能凭这句提示断定一定丢失。无需另设风险栏目。
