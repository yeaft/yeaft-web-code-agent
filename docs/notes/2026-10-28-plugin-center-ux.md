# 插件工作区交互

插件入口位于原有 Session 侧栏的「新建聊天」下方，CLI Chat 与 Yeaft Session 使用相同入口；侧栏的项目、最近会话、设置和宽度不变。

## 布局与导航

- 正文顶部只有一行：Agent 选择器、分类、搜索、创建技能、更多操作。Agent 下拉列表沿用 Session 侧栏的行高、留白与字体，名称始终左对齐；不显示状态圆点或对勾，当前项仅以背景区分，离线项保留文字标记。
- 技能、MCP 和内置工具使用一个对齐列表；详情在同一内容区打开，返回时保留搜索、筛选与列表滚动位置。
- 小屏幕分类收为选择器，搜索在同一行展开，创建技能收进更多菜单。顶部菜单按钮可重新打开 Session 抽屉。
- 点击任意 Session，包括原本已选中的 Session，直接退出插件页。新建聊天和进入 Work Center 同样退出插件页。
- 不再有普通能力开关的「保存 / 关闭」底栏。创建技能仍是显式提交的表单；表单打开时背景不可操作，放弃未提交内容需确认。

## Agent 所有权与保存

- 顶部选择的 Agent 是配置归属，不改变当前 Session 的 Agent。
- 开关乐观更新，由 chat store 持有写入队列；同一 Agent 的写入串行，同一轮快速切换可合并，不同 Agent 独立。
- 页面离开或 Agent 切换不会取消已发出的保存。只有有差异的条目显示小型保存状态，成功不常驻提示。
- 保存失败恢复最近确认配置，保留所属 Agent、错误和重试意图；离开插件页后仍有全局错误提示。
- 不自动重放离线写入。重试先读取 Agent 配置，再按条目意图重新计算，避免用超时前的完整快照覆盖其他配置。
- 配置响应必须属于仍有效的请求、Agent、连接与请求代际；未知、过期、乱序或错误 Agent 的响应不能覆盖缓存。
- 离线 Agent 仅展示当前浏览器登录周期内的缓存，开关和创建 / 删除操作禁用；重连后重新加载，不自动重试失败修改。
- 重新打开或重连刷新配置期间，缓存开关及创建技能禁用；store 对所有新修改（含创建后的自动启用）统一重新读取并合并条目意图，避免旧配置覆盖其他客户端的变更。登录身份或认证代际变化时清理缓存、选择、待处理回复及重试意图；技能确认和创建 / 删除结果同时受页面生命周期、Agent / workspace 与认证代际限制，旧异步任务不能重新写回。

配置保存不等于立即中止运行中的工具。当前 Agent 运行时仍沿用既有 reset / reload 边界，详情中说明这一点。MCP 的启用开关和连接状态分别展示，未连接不能误写为已停用。

## 现有能力边界

插件目录保持轻量，只包含名称、说明、来源、MCP 连接和工具数量；技能详情通过带 `skillName` 的 `yeaft_plugin_catalog` 请求按需读取所选 Agent / workspace 中当前生效的 layered Skill，不把所有 Prompt 混入列表。正文按原文展示，含 HTML 的技能文本不会执行；超过 256 KiB 时明确标注预览截断。引用与模板仅列出名称，不另读文件内容。

技能详情提供 `/skill:<name> 任务描述` 的真实调用方式、通用示例，以及技能声明的触发词 / 关键词；不生成不存在的技能专属用法。当前生效来源与全部安装来源分开展示。读取响应隔离请求、Agent、认证及连接代际；页面切换、关闭或断线后的旧结果不能回填。正文只保存在当前详情组件，不写入 store / 浏览器持久缓存。旧 Agent 未返回 `skillDetail` 时明确提示升级；离线、读取失败和空正文分别展示，不假装加载成功。

本轮不增加插件商城、安装协议、技能编辑协议、MCP 工具清单或在线服务重启；保留原有技能创建和按来源删除能力。

验证通过组件测试、真实 Web / Server / 测试 Agent 中继和浏览器布局检查完成，不修改用户的真实 Agent 配置。
