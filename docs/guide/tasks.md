# 任务

任务把一个可编辑的执行 Prompt 和触发配置绑定到 Yeaft Session。打开任务后，仍然使用同一套对话、消息历史、VP、模型选择、文件和工作台；任务不是 Work Center 的 WorkItem，也不会创建第二份对话记录。

## 创建与使用

在侧栏的“新建聊天”下方、“插件”上方选择“新建任务”。选择支持任务功能的在线 Agent、工作目录和 VP，填写任务名称、Prompt 与触发配置。任务会显示在“项目”和“最近”之间的可折叠“任务”分区，不重复显示为最近聊天。

可以在任务中继续对话，也可以使用“立即执行”按保存的 Prompt 执行。手动执行不消耗或移动下一次定时计划。任务配置支持修改 Prompt、触发时间、重复规则、启停和通知；成员、工作目录等沿用 Session 设置。首版只支持 Yeaft 原生引擎，不将 Claude Code / Copilot CLI 会话当作定时任务执行器。

## 触发配置

- **手动**：仅在用户选择立即执行时触发。
- **定时**：支持一次性时间，以及每日、工作日、每周、每月的日历规则与时区。
- Connector 事件触发属于后续能力，目前不连接事件源，也不展示为可用触发器。

重复规则使用指定时区而非浏览器或 Agent 的隐式本地时区。夏令时中不存在的墙钟时间跳过，重复的墙钟时间只执行一次；月末规则采用现有日历计算规则。

## 执行与恢复

调度运行在 Agent 机器，配置保存在当前 Agent 实例的数据根。关闭浏览器不影响在线 Agent 的定时调度；Agent 离线或进程停止时无法执行。Agent 重连后先恢复 Server 权威的 Project 指令（包括明确无 Project 的状态），同步完成前不启动任务，也不消费等待中的一次性计划。任务使用用户选择的 VP、目录、模型与现有工具权限，执行可能调用模型 API 并产生文件或外部系统副作用；定时任务不会额外扩大执行权限。

同一任务不叠加启动；运行时到期的触发和离线期间错过的重复时间不无限补跑。重启时遗留的运行会标记为中断，不自动重新执行可能已经产生副作用的请求。暂停、修改计划、归档或删除不会让已取消的旧计划重新启动。

执行输出写入任务自己的 Session 历史。任务的“完成”表示本次 Agent 执行生命周期结束，不代表系统替用户验证了 Prompt 中每一项业务验收条件；检查结果和工具证据仍然是必要的。

## 通知

启用通知后，任务执行结束会显示可点击通知，点击进入对应 Agent 上的任务。通知按 `(agentId, sessionId, runId)` 隔离并去重。重新连接时通过任务的上一次运行状态恢复最近一次结果提醒，不是无限历史通知中心。浏览器已授予系统通知权限时还可收到桌面通知；未授权时仍保留应用内通知，不会在后台自动弹出权限请求。

旧版 Agent 不会静默把任务创建为普通聊天，需要先按正常发布与运维流程更新 Agent。代码发布不会自动升级或重启用户正在运行的实例。
