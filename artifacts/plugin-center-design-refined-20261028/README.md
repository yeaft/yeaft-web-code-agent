## 这次的设计决定

### 左侧：保持现有 Session sidebar

- 使用现有 `SessionSidebarShell`、`SidebarAgentHeader`、`UnifiedSessionList` 和 sidebar 主题样式，不再自绘另一套导航。
- 保留宽度、顶部 Agent 入口、项目与最近会话层级、文字密度、列表样式和底部设置入口。
- **仅把插件入口从底部移动到「新建聊天」正下方**，沿用同一行高、缩进和图标尺寸；当前插件页有选中背景。
- 页面内不再添加第二个 Agent 侧栏。
- 顶部数字人 / Work Center 图标在原型中仅示意原有入口；正式产品仍按现有功能开关显示，不新增或开启能力。

### 右侧顶部：只有一行

顺序：**Agent 选择器 → 全部 / 技能 / MCP / 内置工具 → 搜索 → 创建技能 → 更多**。

- Agent 是正文最先可见的控件。点击后展开实例列表，不把所有 Agent 常驻在正文里。
- 桌面 header 高 64px，窄屏 56px，不换行堆叠。
- 删除大标题、副标题、第二行作用域、第三行保存状态、重复统计数字与常驻说明。
- 更多菜单收纳「只看已启用」「刷新」等低频操作。
- 窄屏将分类收为选择器，搜索点开后替换同一行内容；创建技能收进更多菜单，不增加 header 高度。

### 正文：一个统一列表

- 不再将技能、MCP、内置工具各套一层区块与摘要卡。
- 单列固定对齐：图标、名称 / 一句描述、类型、来源、开关。
- 类型和来源弱化，不做一串 badge；窄屏隐藏次要列，详情仍可查看完整信息。
- 点击名称或主要内容进入详情；开关是独立点击目标，不误触详情。
- 详情复用同一行顶部 Agent 工具栏，下面只展示名称、内容、必要信息和相关操作，不再重复解释保存与作用范围。

## 交互保持

- 普通开关按 Agent 自动保存，不保留页面底部的保存 / 关闭栏。
- 保存中只在对应条目开关旁出现小型状态；保存成功安静消失，不逐次弹 toast。
- 只有离线、加载失败、保存失败或待应用等真实异常 / 待处理状态需要主动提示；不为了简洁隐藏故障。
- 保存失败回滚，提示包含所属 Agent 并提供重试；切换 Agent / Session 后也不能串写或悄悄丢失错误。
- 点击任意 Session，包括之前已经选中的 Session，直接退出插件页进入对话，无需先点关闭。
- 正式实现的自动保存应由 Agent-scoped store 管理，不依赖当前页面是否仍挂载；异步写入需串行 / 合并、处理响应乱序。
- 开关保存和运行时生效不是同一状态。后续实施需核对真实的 reload / reset 边界，不能把保存成功说成在途调用已停止。
- 技能编辑表单、MCP 配置表单、真实网络请求、history routing 与加载 / 重连恢复不在本静态原型范围，待视觉确认后实施。
